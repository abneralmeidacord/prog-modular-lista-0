# Nivelamento - Lista de Revisão de Programação

Repositório destinado às atividades de nivelamento da disciplina de **Programação Modular**.

**Instituição:** Pontifícia Universidade Católica de Minas Gerais
**Professor:** Glender Brás
**Disciplina:** Programação Modular

## Instruções

* Criar um repositório público no GitHub;
* Criar uma nova branch para cada atividade proposta;
* Realizar a entrega pelo Canvas através do link do repositório;
* A lista não será pontuada, mas sua realização é recomendada para revisão dos conhecimentos de programação.

## Organização

Cada atividade será desenvolvida em uma branch diferente:

```text
main
atividade-01
atividade-02
atividade-03
...
```
